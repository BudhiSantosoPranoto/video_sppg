# 0. GLOBAL PRODUCTION RULES

## Visual Style
Use:
- photorealistic cinematic documentary-commercial;
- realistic Indonesian SPPG environment;
- premium but believable production quality;
- natural human expressions;
- realistic lighting and materials;
- restrained camera movement;
- documentary credibility rather than advertising gloss.

Avoid:
- generic stock-photo appearance;
- exaggerated cinematic effects;
- horror aesthetics;
- excessive lens flare;
- surreal water;
- cartoonish microorganisms;
- overly perfect “AI faces”;
- fake government logos or official insignia.

## Product Consistency
### The New eSpring™
Use ONLY the locked New eSpring product reference supplied by the project.

Never:
- substitute the old eSpring model;
- invent a different casing;
- change front panel geometry;
- change proportions;
- invent controls, displays, connectors or faucet;
- redesign the product;
- create a generic “water purifier” that merely resembles eSpring.

### HYDRO
Use the approved real HYDRO reference from project materials.

Do not invent HF 4000 / HF 6000 / HF 8000 geometry or specifications. If the model is not explicitly shown in the reference image, use a neutral HYDRO system visual.
